# Playwright E-commerce Automation



## Project Overview



This portfolio project demonstrates practical Automation QA engineering using Playwright and TypeScript.



The framework will progressively cover e-commerce application testing, including login, product search, basket and checkout.



## Technology Stack



- Playwright

- TypeScript

- Node.js

- Git and GitHub

- GitHub Actions

- Docker

- Kubernetes

- Jenkins (planned)



## Current Test Coverage



The initial framework contains Playwright starter smoke tests that verify page title and navigation behaviour.



These tests currently run against Chromium, Firefox and WebKit.



E-commerce-specific test scenarios will be added progressively.



## Setup



Install dependencies:



```bash

npm ci

```



Install Playwright browsers:



```bash

npx playwright install

```



Run all tests:



```bash

npx playwright test

```



Open the HTML report:



```bash

npx playwright show-report

```
